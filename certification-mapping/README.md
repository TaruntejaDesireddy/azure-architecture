# Certification mapping

The modules are built around **Azure security engineering competencies**, not around an exam
syllabus. This folder maps them onto certifications after the fact, so the repo stays useful when
an exam changes or retires.

| Exam | Folder | Modules it draws on |
|---|---|---|
| SC-300 — Identity and Access Administrator | [sc-300/](sc-300/) | 02–11 |
| SC-200 — Security Operations Analyst | [sc-200/](sc-200/) | 31–45 |
| SC-100 — Cybersecurity Architect | [sc-100/](sc-100/) | 47–57 |
| AZ-500 — Azure Security Engineer | [az-500/](az-500/) | 01, 12–30 |

> **AZ-500 retires 31 August 2026.** After that it can be neither earned nor renewed. It is kept
> here as a historical mapping rather than a target — which is exactly why the modules are
> organised by competency instead. Its successor is SC-500, with no announced transition path.

The paced, exam-shaped tracks live in [`azure-soc-lab`](https://github.com/TaruntejaDesireddy/azure-soc-lab/blob/main/START-HERE.md).
